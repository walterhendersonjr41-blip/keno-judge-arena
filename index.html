Project overview

Keno Judge Arena

A 24/7 research lab that tests whether AI can beat random chance on Tennessee Keno. Three independent Player AIs (Alpha, Beta, Gamma) each predict every upcoming draw. A neutral Judge AI scores them against the official result, keeps lifetime leaderboards and consensus stats, and only "releases" a pick if the evidence ever shows a player doing better than random. By default it withholds.

About this page. The app needs its FastAPI backend, MongoDB and LLM access, so it can't run on GitHub Pages. This page explains it; the full source is in backend/ and frontend/. Keno draws are random: this is a research and entertainment project, not betting advice.

Each round

  1. Fetch the official draw (or accept a pasted import)
  2. Score every prediction that targeted it
  3. Players make fresh 5/6/7/8-pick predictions for the next draw, in parallel and blind to each other
  4. The Judge updates XP, reputation and consensus, and decides whether to release anything

How it's built

Backend: Python FastAPI, APScheduler (30 s pipeline tick plus a slower feed fetch), MongoDB (Motor), draw source with simulation fallback and manual paste import, pytest suite. Frontend: React + Tailwind + shadcn/ui. AIs: three different LLMs as players plus a Judge, via the Emergent LLM integration (key from env).
